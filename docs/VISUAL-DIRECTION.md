# Visual Direction

## Positioning

Brisas de la Cayana should feel like an editorial travel story rooted in the real landscape of Villa Alpina.

The target perception is:

- natural
- warm
- quiet
- authentic
- intimate
- slightly rustic
- visually refined without feeling luxurious or artificial

The site should never make the property look like a generic Scandinavian lodge, a resort, or an urban boutique hotel. The visual system must preserve the roughness and reality of the place: changing weather, mountain vegetation, wood, horses, creek stones, mist, strong sun and open sky.

## Central visual idea

**The landscape is the main character; the cabin is the refuge inside it.**

Whenever possible, use photographs where the building occupies a smaller portion of the frame and the environment carries the emotional weight.

## Reference principles

Borrow qualities rather than layouts:

- travel-editorial pacing
- large images with intentional whitespace
- short, literary section titles
- restrained navigation
- generous typography
- asymmetry where it helps the images breathe
- quiet transitions rather than app-like UI
- tactile, natural surfaces rather than glossy gradients

Avoid:

- generic hotel card grids
- excessive rounded cards
- glassmorphism
- heavy shadows
- luxury-gold clichés
- stock icons for every amenity
- oversized badges and ratings
- constant carousel motion
- over-designed booking widgets

## Typography

### Display / editorial

Preferred direction: **Instrument Serif** or another elegant but imperfect editorial serif.

Use for:

- hero statement
- chapter titles
- short emotional lines
- selected pull quotes

The serif should feel human and literary, not formal or wedding-like.

### Sans serif

Preferred direction: **Geist**, **Inter**, or **Manrope**.

Use for:

- body copy
- navigation
- utility text
- form labels
- buttons
- practical information

### Scale

Desktop hero title can be very large but should remain controlled. Mobile typography must preserve hierarchy without becoming poster-like.

Suggested rhythm:

```text
Eyebrow / utility     12–14px
Body                  16–18px
Large body / intro    20–24px
Section title         42–72px desktop
Hero title            64–110px desktop
```

Use fluid sizing rather than fixed breakpoints where practical.

## Color and contrast

The palette should come from the actual place rather than from a generic hospitality moodboard.

Working direction:

```text
Warm cream / paper      #F4F0E7
Stone                   #E4DED1
Mountain green          #596052
Earth brown             #765D46
Deep charcoal           #292A27
Soft off-white          #FAF8F2
```

These values are starting points, not immutable brand colors. Final values should be tuned against the chosen photography.

### Use

- warm cream for long reading sections
- deep charcoal for body text
- mountain green for restrained accents
- earth brown only where it supports the natural palette
- white text only over photographs with sufficient overlay / contrast

No low-contrast beige-on-beige typography for essential content.

## Photography / imagery

Photography is the dominant visual system.

The image collection already suggests six useful families:

1. hero / impact
2. landscape / place
3. cabin / interiors
4. experience / activity
5. quiet details / atmosphere
6. practical arrival / access

### Preferred qualities

- wide landscapes
- natural light
- authentic weather
- visible texture
- human scale
- environmental context
- compositions with negative space
- images that allow the visitor to imagine standing there

### Strong motifs already present

- cabin isolated in the landscape
- mountain road / arrival
- creek and stones
- white outdoor chairs facing nature
- horses / horseback riding
- trails
- deck / veranda
- food or drink facing the landscape
- fog / cloud / winter atmosphere
- sunset silhouettes

### Avoid

- using screenshots of Instagram posts as final assets
- text embedded inside photographs
- repeating nearly identical exterior photos
- showing every image simply because it exists
- heavy filters that make different seasons look artificially consistent
- AI-generated replacement photography for the real property

Original high-resolution owner-provided files should be used for the final version.

## Image treatment

Most photographs should remain close to their original color.

Allowed processing:

- subtle crop
- exposure normalization
- restrained contrast correction
- very light tonal consistency when needed

Avoid global presets that flatten mist, winter, blue skies and sunset into the same look. Seasonal variation is part of the identity.

## Layout language

### General

- generous vertical spacing
- long editorial sections
- alternating density: image-heavy chapter followed by quiet text chapter
- occasional full-bleed transitions
- no rigid 12-card dashboard feeling

### Image compositions

Use several recurring patterns:

```text
A. full-bleed landscape
B. 60/40 image + text
C. asymmetric two-image spread
D. narrow portrait image beside large typography
E. large image with short caption below
F. quiet text-only pause
```

The site should feel composed, not templated.

## UI language

### Buttons

Primary buttons should be clear and calm.

- moderate radius, not pill-shaped by default
- strong contrast
- generous horizontal padding
- minimal icon use

Example:

```text
Consultar disponibilidad  →
```

### Cards

Avoid cards for ordinary content. Use them only where grouping is useful, such as practical arrival notes or a compact availability module.

### Borders

Prefer subtle 1px dividers and whitespace over shadowed containers.

### Icons

Use simple line icons sparingly for practical information. Emotional/storytelling sections should rely on photography and typography instead.

### Motion

Motion should be slow and almost invisible:

- small image reveal
- gentle fade / translate
- restrained header transition
- no parallax that harms readability
- no auto-scrolling galleries
- respect `prefers-reduced-motion`

## Logo / brand handling

Use the existing Brisas identity only if the available logo is suitable at web resolution and its use is approved.

The page should still work typographically without relying on the logo. `Brisas de la Cayana` can be rendered as text in the header while the existing mark is used selectively.

## Section mood map

```text
Hero                  expansive / quiet
Slow down             contemplative
Cabin                  warm / grounded
Experience             active / open
Do nothing             sparse / still
Story                  human / intimate
Practical info         clear / reassuring
Gallery                immersive
Location               concrete / orienting
Booking                simple / decisive
```

## Final visual test

Before publication, ask:

- Could this exact design be rebranded for any random cabin in five minutes?
- Does the landscape feel more important than the UI?
- Is the site beautiful even without decorative effects?
- Are practical sections as legible as emotional sections?
- Does mobile retain the same atmosphere as desktop?

If the first answer is yes, the design is not specific enough to Brisas.
